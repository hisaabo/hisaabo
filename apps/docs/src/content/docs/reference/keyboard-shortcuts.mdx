Hisaabo supports keyboard shortcuts on the **web app** to speed up your workflow. These shortcuts are not available on mobile.

## Navigation

All navigation shortcuts use `Alt + Shift + Key` (or `Option + Shift + Key` on Mac).

| Shortcut | Action |
|---|---|
| `Alt+Shift+D` | Dashboard |
| `Alt+Shift+I` | Invoices |
| `Alt+Shift+Q` | Quotations |
| `Alt+Shift+C` | Credit Notes |
| `Alt+Shift+P` | Parties |
| `Alt+Shift+T` | Items |
| `Alt+Shift+M` | Payments |
| `Alt+Shift+B` | Cash & Bank |
| `Alt+Shift+E` | Expenses |
| `Alt+Shift+G` | GST Returns |
| `Alt+Shift+R` | Business Reports |
| `Alt+Shift+S` | Settings |

:::note
Keyboard shortcuts are disabled when focus is in a text input field to avoid accidental triggers.
:::

:::tip
On macOS, use `Option` instead of `Alt` — e.g., `Option+Shift+I` to open Invoices.
:::
