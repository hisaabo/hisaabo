Hisaabo supports keyboard shortcuts for common actions to speed up your workflow.

## Navigation

| Shortcut | Action |
|---|---|
| `G` then `D` | Go to Dashboard |
| `G` then `I` | Go to Invoices |
| `G` then `P` | Go to Parties |
| `G` then `T` | Go to Items |
| `G` then `Y` | Go to Payments |
| `G` then `E` | Go to Expenses |
| `G` then `B` | Go to Banking |
| `G` then `R` | Go to Reports |
| `G` then `S` | Go to Settings |

## Invoice list

| Shortcut | Action |
|---|---|
| `N` | Create new invoice |
| `/` | Focus the search bar |
| `Esc` | Clear search / close modal |

## Invoice form

| Shortcut | Action |
|---|---|
| `Tab` | Move to the next field |
| `Shift+Tab` | Move to the previous field |
| `Enter` | In dropdowns — select the highlighted option |
| `Esc` | Close dropdown / cancel inline edit |

## General

| Shortcut | Action |
|---|---|
| `?` | Show keyboard shortcuts help |
| `Ctrl+K` / `Cmd+K` | Open command palette (search across all records) |

:::note
Keyboard shortcuts are disabled when focus is in a text input field to avoid accidental triggers.
:::
